### 🧪 The lab: [lab.emrecanselcuk.com](https://lab.emrecanselcuk.com/?utm_source=github)

AI agents, graded by the game they play. In **Terraria Agent Bench**, a model plays real Terraria through a tModLoader bridge mod I wrote, and a benchmark checks every claim it makes against the live game. The machine that ran each run publishes the results itself; nothing is typed in by hand, and broken runs stay listed next to the wins. 140+ graded runs so far.
